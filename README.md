# Sonnenhof der Koboldtiere

Standalone-Website für den Sonnenhof der Koboldtiere.

`index.html` ist die aktuelle Arbeits- und Veröffentlichungsfassung. Sie basierte auf dem früheren Tailscale-Entwurf; die Tailscale-Adresse ist seit 2026-09-22 archiviert und nicht mehr aktiver Zugriffsweg.

Die ältere, an Lara geschickte Fassung (`backup/initial-version/`) und die frühere GitHub-Fassung (`backup/github-edited-version/`) liegen nur noch lokal und in der Git-Historie (bis Commit 955f8e5). Seit 27.11.2026 ist `backup/` ignoriert, damit die alten Stände nicht öffentlich erreichbar sind.

## Lokal öffnen

`index.html` direkt im Browser öffnen.

## Veröffentlichung

Die Website wird aus diesem Repository über GitHub Pages veröffentlicht:

https://sonnenhof-der-koboldtiere.de/ (Domain über `CNAME`; jeder Push auf `master` ist der Livegang)
